# 🎓 Concierge Study Agent

![Python](https://img.shields.io/badge/Python-3.9%2B-blue)
![Status](https://img.shields.io/badge/Status-Active-success)

**Your AI-Powered Personal Study Companion.**

The Concierge Study Agent is a sophisticated CLI tool designed to revolutionize how you prepare for exams. By leveraging the power of **Google Gemini AI**, it transforms static PDF syllabi into dynamic, self-healing study schedules that adapt to your pace.

---

## ✨ Key Features

- **📄 Intelligent Syllabus Parsing**: Automatically extracts topics, difficulty levels, and estimated study hours from PDF documents.
- **📅 Dynamic Scheduling**: Generates a study plan that targets finishing the syllabus **10 days before your exam**, ensuring ample time for revision.
- **🛡️ Revision Buffer**: Automatically adjusts the schedule to maintain a safety buffer for final review.
- **⚔️ Daily Battle Plan**: Provides a daily dashboard with tasks and AI-generated motivational briefings to keep you focused.
- **🧠 Smart Strategy**: Generates "brutal" and effective micro-strategies for mastering specific topics.
- **🔁 Spaced Repetition**: Automatically schedules review sessions 3 days after you mark a task as done to combat the forgetting curve.

## 🚀 Getting Started

### Prerequisites

- Python 3.9 or higher
- A Google Cloud Project with the **Gemini API** enabled.
- An API Key for Google Gemini.

### Installation

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/yourusername/study_agent.git
    cd study_agent
    ```

2.  **Create a Virtual Environment (Recommended)**
    ```bash
    python -m venv venv
    # Windows
    venv\Scripts\activate
    # macOS/Linux
    source venv/bin/activate
    ```

3.  **Install Dependencies**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Configuration**
    Create a `.env` file in the root directory as shown in .env.sample

## 📖 Usage

Start the application by running:

```bash
python main.py
```

### Main Menu Options

#### 1. 📤 Upload New Syllabus
- **Input**: Path to your PDF syllabus, Subject Name, and Exam Date.
- **Process**: The AI analyzes the document and builds a custom schedule.
- **Output**: A saved study plan in the local database.

#### 2. 📊 View Dashboard
- Check your **"Today's Mission"**.
- See a prioritized list of tasks (Learning vs. Revision).
- Receive a daily motivational quote generated by AI based on your workload.

#### 3. 📚 Subject Details
- **View Schedule**: See the entire timeline for a subject.
- **Mark Done**: Complete a task. *Note: This triggers a "Review" task 3 days later.*
- **Get Strategy**: Select a topic to receive a custom study strategy (Concept, Action, Trap).

## 🔧 Troubleshooting

**Issue: "File not found" when uploading PDF**
- Ensure you are providing the **absolute path** or the correct relative path to the PDF file.
- Example: `C:\Users\Name\Downloads\syllabus.pdf`

**Issue: API Errors**
- Check your `.env` file to ensure `GEMINI_API_KEY` is set correctly.
- Verify you have an active internet connection.

**Issue: "Compressed schedule active"**
- This warning appears if your exam date is too close. The agent has reduced the revision buffer to fit all topics.
